# foodbuddy

##Steps to run the project locally

- Clone the repository in your local machine. 
  ``` bash
  git clone https://github.com/Rajatsharma-07/foodbuddy.git

- Enter into your project folder
  ```bash
  cd foodbuddy

- Install all the packages
  ```bash
  yarn install

- Create a new file .env and copy the content from env.sample into this file.

- Run your project
  ```bash
  yarn start

- Your project is running on `http://localhost:3000`.

Happy Coding!
